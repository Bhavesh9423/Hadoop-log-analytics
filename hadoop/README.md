# Hadoop MapReduce Log File Analytics

This folder contains the core MapReduce programs and scripts designed for **Hadoop Streaming** and local simulation.

## Architecture

```
                       [ RAW LOG FILE ]
                              │
                              ▼
                       [ HDFS Storage ]
                   (/loganalysis/input/...)
                              │
                              ▼
                    [ MAPPER (mapper.py) ]
              Line-by-line regex parsing & tokenization
              Emits intermediate: <Key, Count=1>
                              │
                              ▼
                   [ SHUFFLE & SORT PHASE ]
             Hadoop partitions, transfers, and sorts
               keys alphabetically across nodes
                              │
                              ▼
                   [ REDUCER (reducer.py) ]
             Aggregates counts for each unique key
             Emits final: <Key, Total_Count>
                              │
                              ▼
                     [ HDFS Final Output ]
                   (/loganalysis/output/part-*)
```

## Files in this Directory

- **`mapper.py`**: Python mapper script compatible with Hadoop Streaming (`sys.stdin` -> `sys.stdout`).
- **`reducer.py`**: Python reducer script compatible with Hadoop Streaming (`sys.stdin` -> `sys.stdout`).
- **`run_hadoop_streaming.sh`**: Linux/macOS launcher script for Hadoop clusters.
- **`run_hadoop_streaming.bat`**: Windows launcher script for Hadoop clusters with Winutils.

## Emitted Keys Format

| Key Prefix | Example | Description |
|---|---|---|
| `TOTAL_REQUESTS` | `TOTAL_REQUESTS \t 1` | Total count of all requests processed |
| `TOTAL_SUCCESS` | `TOTAL_SUCCESS \t 1` | Requests with HTTP status 2xx and 3xx |
| `TOTAL_ERRORS` | `TOTAL_ERRORS \t 1` | Requests with HTTP status 4xx and 5xx |
| `STATUS_<CODE>` | `STATUS_200 \t 1` | HTTP status code breakdown |
| `STATUS_CAT_<CAT>` | `STATUS_CAT_2xx \t 1` | HTTP status category (2xx, 3xx, 4xx, 5xx) |
| `URL_<PATH>` | `URL_/products \t 1` | Visited endpoint URL |
| `IP_<ADDRESS>` | `IP_192.168.1.10 \t 1` | Client IP address frequency |
| `METHOD_<HTTP_VERB>`| `METHOD_GET \t 1` | HTTP method distribution |
| `TIME_HOUR_<YYYY-MM-DD HH:00>` | `TIME_HOUR_2026-10-01 14:00 \t 1` | Hourly aggregated traffic |
| `TIME_DAY_<YYYY-MM-DD>` | `TIME_DAY_2026-10-01 \t 1` | Daily aggregated traffic |
| `ERROR_CODE_<CODE>` | `ERROR_CODE_404 \t 1` | Specific error code occurrences |
| `ERROR_URL_<PATH>` | `ERROR_URL_/admin \t 1` | Most error-affected endpoints |
| `IP_ERR_<ADDRESS>` | `IP_ERR_192.168.1.12 \t 1` | Number of errors generated by IP |
| `IP_SUCC_<ADDRESS>`| `IP_SUCC_192.168.1.10 \t 1` | Number of successful requests by IP |

## Running on an Actual Hadoop Cluster

### 1. Create HDFS Directory
```bash
hdfs dfs -mkdir -p /loganalysis/input
```

### 2. Upload Log File to HDFS
```bash
hdfs dfs -put sample_access.log /loganalysis/input/
```

### 3. Verify File in HDFS
```bash
hdfs dfs -ls /loganalysis/input
hdfs dfs -head /loganalysis/input/sample_access.log
```

### 4. Execute Hadoop Streaming Job
```bash
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-*.jar \
    -D mapreduce.job.name="Hadoop_Log_Analytics" \
    -D mapreduce.job.reduces=2 \
    -files mapper.py,reducer.py \
    -mapper "python3 mapper.py" \
    -reducer "python3 reducer.py" \
    -input /loganalysis/input/sample_access.log \
    -output /loganalysis/output
```

### 5. Inspect Results in HDFS
```bash
hdfs dfs -ls /loganalysis/output
hdfs dfs -cat /loganalysis/output/part-* | head -n 30
```

### 6. Copy Output to Local Filesystem
```bash
hdfs dfs -getmerge /loganalysis/output final_aggregated_results.txt
```
